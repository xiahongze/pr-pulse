# Changelog

## 0.1.0 — 2026-10-02

- Initial Plasma 6 widget listing PRs assigned to you, opened by you, or awaiting your review, fetched with one `gh api graphql` call
- Configurable `gh` path with PATH and common-location fallback, plus clear messages for missing or logged-out gh
- GitHub Octicons and Primer status colours for PR state, CI rollup, and review decision
- Role, status, CI, repository, author, and text filters that persist across restarts, plus clickable status chips
- System, light, and dark themes; desktop opacity; panel badge for open or attention-needing PRs
- Recently merged and closed history (7 days by default), 3-minute default refresh, and a pin for the taskbar popup
- Popup size scales with the Plasma font grid unit so it opens wide enough without resizing
- Tests, packaging, CI, and tag-driven release automation
